# Databricks Private Network Gateway — Pre-flight Checklist

An interactive pre-flight checklist for Databricks serverless **Private Network Gateway (PNG)** on **Azure** (Public Preview) and **AWS** (Private Preview): prerequisites, gateway subnet and network path, DNS, traffic mode and egress control, Networking v1 API calls, validation tests, troubleshooting by symptom, and lifecycle.

Items are tagged **Docs** (official documentation) or **Field-tested** (observed in preview deployments; may change).

Live: https://chriscwmoon.github.io/databricks-png-preflight-checklist/
